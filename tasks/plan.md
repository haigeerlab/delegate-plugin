## 目标与设计

先修复中文阅读路径和事实错误，再提供完整英文对应版本。中文 README 保持仓库默认入口，英文入口为 `README.en.md`。当前维护的设计、能力图、三份规格、贡献说明、文档索引和版本说明均提供英文版本。

同一个插件使用两套文档，不复制插件、不增加语言配置、不改命令、hook、脚本、清单或产品测试。运行时提示继续使用现有语言。历史计划和任务加归档说明，保留历史事实和勾选状态。

- 中文与英文读者均能独立了解定位、安装、首次委托、验收、更新、卸载、排障及贡献流程。
