# 公开材料的脱敏说明

简体中文 | [English](2026-10-08-public-redaction.en.md)

本页说明公开版与本地执行证据的区别；脱敏没有重新执行模型或补出历史批准。用户目录以 `<PROJECT_ROOT>` 代替，本机临时目录以 `<LOCAL_TMP>` 代替，原生会话目录以 `<NATIVE_SESSION>` 代替。这些占位符不是可直接执行的实际路径。

[衍生材料清单](2026-10-08-public-redaction.json)记录 22 份材料的原始与公开 SHA-256。原始文件和完整原生日志保留在本地，不随公开分支交付。八份接入前 `.md.txt` 原文归档没有脱敏改写。

旧批次 JSON 中的 checker 哈希、通过标志和命令输出属于当时原始本地材料的快照。脱敏后的 `.py.txt` 是供阅读的衍生脚本，不能以旧快照哈希核对它，也不能将旧 checkerArchiveHashMatched 解释为公开衍生脚本已通过原字节核验。当前逐项证据索引的 VAL 哈希改为公开报告的哈希，其余 32 个索引不变；119 条裁决、完成与人工批准字段不变。

现有结论仍为 106 当前支持、13 合同替代、0 待验证；119 条历史完成与人工批准全部 unknown。完整产品覆盖、永久回归及失败重派授权等边界保持原记录。公开脱敏不扩大验收结论。
