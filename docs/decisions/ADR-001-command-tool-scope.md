# ADR-001：保留委托命令的现行 Bash 声明

简体中文 | [English](../en/decisions/ADR-001-command-tool-scope.md)

状态：Accepted。日期：2026-10-08。批准来源：用户在具体批次 A/B 的一次确认请求后回复“继续”。仅记录当前决定，不追认历史批准。

## 背景

旧归档 channel:7-A1 要求 Bash(固定脚本路径 *)，现行命令从首次引入就声明 allowed-tools: Bash。提交 cd0ebafb28723a7d195de9ee029f8832670e0885 记录固定 glob 会随安装路径变化失效；开发者解释本身不是人工批准。

## 决定

保留现行 Bash 声明。命令仍要求明确任务授权、默认只读，写入须另获当轮授权；运行时、插件声明及安装均未修改。旧固定路径的字面条件归为现行合同替代，不标为已满足。

## 备选与后果

固定安装路径会损害跨安装位置的可用性；变量形式的窄规则没有本轮兼容性验收，因此不直接替换。
Bash 范围较广，文本确认纪律不能提供工具级最小权限或不可绕过的授权锁。未来若要求收窄，需另定规则并在源码/user 安装路径中实际验收。所有历史完成及批准继续 unknown。
