# v0.8.2：run 命令说明跟上接口 1.3

简体中文 | [English](../en/releases/v0.8.2.md)

这是 v0.8.1 之后的补丁版，**只改 `/delegate:run` 的命令说明，行为不变**。接口说明仍为 `1.3`，脚本、命令参数、期限、结果行、结果文件和退出码都与 v0.8.1 相同；不需要迁移。

`commands/run.md` 是宿主调用 `/delegate:run` 时加载的提示词（module-crew 的模块会话就是这样调用的）。v0.8.1 补齐了其他文档，但这份提示词里还有两处写在 1.3 之前的说法，本版改正。

## 修正

- **写入授权**：原来写「只有用户在该轮明确要求写文件才能加 `--write`」，现在写明 `--write` 须用户在该轮明确要求，唯一例外是 `references/run.md` 里写入授权的四个条件全部满足、并带 `--authorized-by`；任一条不满足就回到当轮要求，不自行升级权限。这条例外 v0.8.0 已在 [run-check](../../spec/run-check.md) 中批准，并写进了 `references/run.md` 和 `delegate-routing` skill；本版只是把它写到命令说明里，不放宽任何条件。
- **期限**：原来写「默认/上限 540 秒」，现在写明默认 540 秒，`--timeout` 可放大到 541～7200 秒，超过 540 秒必须用宿主的后台模式调用（[run-longrun](../../spec/run-longrun.md) S9）。
- **日志位置**：「旧过程日志位于…」改为「过程日志与结果文件在…」，与 1.3 的结果文件对上。
- **为守住 Codex 的 4000 字节上限**（Codex 把命令转成 skill 时超过就跳过），删去三处重复说法：「需要共同结构化审查时也使用 review」（同一行已写 Claude 只通过 `/delegate:review` 做只读审查）、「不用本机配置的审批方式」（已有 `approval_policy="never"`），以及 v0.5.0 的迁移旧话（完整迁移说明仍在 `/delegate:help`）。改后转换为 3971 字节。

`delegate-routing` skill 经核对没有过时说法，本版未改。

## 验证与已知限制

没有改代码和测试。免费总验证仍为 328 项 Python、53 项 shell 和 19 项 eval，25 个循环注册的 Python 回归套；命令体积测试通过；`claude plugin validate` 对 marketplace 和插件都通过。本版没有付费调用。

根 README 与插件 README 写的是「`--timeout` 超过宿主前台期限时用后台模式」，命令说明和 skill 按 S9 写「超过 540 秒就用后台模式」；两种说法都出自 run-longrun 规格，后者更严，本版没有统一。v0.8.0 列出的其余未验证项不变。

## 更新

运行 `claude plugin update delegate@delegate-marketplace`，然后打开新会话或执行 `/reload-plugins`。从 v0.8.1 升级不需要迁移；正在用 `/delegate:run` 的会话要重新加载，才会读到新的命令说明。
