# v0.12.5：Claude 登录令牌过期时给出恢复提示

简体中文 | [English](../en/releases/v0.12.5.md)

## Claude 登录令牌过期时给出恢复提示

Claude 登录令牌过期后，`review --backend claude-code` 必然失败，而体检和 `claude auth status` 照样显示已登录，报告只有 `claude_api_authentication_failed`，使用方不知道怎么恢复。现在遇到这种失败时，报告 `diagnostics` 再追加固定码 `claude_login_refresh_required`，stderr 打一行固定提示：在沙箱外的终端运行一次 `claude`（例如 `claude -p "ok"`）刷新登录后重试，仍失败时运行 `claude /login`。`/delegate:doctor --backend claude-code` 也说明「已登录不代表令牌仍然有效」并给出同一提示。delegate 不替用户刷新令牌，不读写凭据。

## 影响面

只影响 Claude Code 后端审查失败时的诊断码与 stderr，以及 claude-code 体检多一行说明。报告字段、退出码与接口版本（1.7）不变；Codex 后端和 run 不受影响。

## 验证与已知限制

新增回归（修复前均失败）：认证失败事件得到两个码且顺序正确、其他 API 错误不追加；公开入口（显式 claude-code 与 auto）stderr 恰好一次固定提示、无该码时没有、stdout 只有 JSON；体检打印说明行、`--reviewers` 不变。令牌过期无法按需制造，真实效果待遇到时用安装版记录。

本次发版准备实测：免费总验证 551 项 Python，循环注册的 Python 回归套 31 个。

## 更新

- Claude Code：运行 `claude plugin update delegate@delegate-marketplace`，然后打开新会话或执行 `/reload-plugins`。
- Codex：把 `~/.codex/config.toml` 里 `[marketplaces.delegate-marketplace]` 的 `ref` 改成 `"v0.12.5"`，再运行 `codex plugin marketplace upgrade delegate-marketplace` 和 `codex plugin add delegate@delegate-marketplace`，然后重开会话。
