# v0.5.3：发布对外接口说明与审查报告合同

简体中文 | [English](../en/releases/v0.5.3.md)

这是 v0.5.2 之后的小版本，命令、参数、权限边界和报告内容都不变。从 v0.5.2 升级不需要迁移。

## 新增

- **`interface.json`**：插件根目录新增接口说明（接口版本 `1.0`），声明 `/delegate:review` 支持 codex 与 claude-code 两个只读后端、报告 `schemaVersion: 1`，`/delegate:run` 只支持 codex 且写入需显式授权。其他插件可以按版本范围（如 `>=1.0,<2.0`）判断能否对接，不必读 delegate 的内部文件。`backends` 只表示支持哪些后端，不代表本机已安装、已登录或有额度，能否运行仍以 `/delegate:doctor` 为准。
- **审查报告对外合同**：插件 README 新增“对外接口”一节，写明 `/delegate:review` 的标准输出就是报告 JSON，列出 v1 的稳定字段（执行状态、审查结论、后端、审查对象指纹、已审与未审文件、发现、限制说明）和解读规则：只有 `execution_status=completed` 且结论为 `findings` 或 `no_findings_in_scope` 才算有结论；报告是参考意见，不是用户批准。
- **一致性测试**：新增 `test-interface.py`，从源码取事实比对接口说明与报告合同，字段或后端变化时测试会失败。

## 验证与已知限制

免费总验证覆盖 173 项 Python（比 v0.5.2 多 7 项）、53 项 shell 和 19 项 eval；`claude plugin validate` 对 marketplace 和插件都通过。本版只新增静态文件、测试和文档，没有新增模型调用。

使用方对接由各插件自行实现：spec-guard 当前版本只按“已安装并启用”提示可用 `/delegate:review`，按接口版本校验将在本版发布后另行实现。v0.5.0 列出的其余未验证项不变。

## 更新

运行 `claude plugin update delegate@delegate-marketplace`，然后打开新会话或执行 `/reload-plugins`。
