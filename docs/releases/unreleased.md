## 事先写入授权认可 autopilot-hub

`run --write --authorized-by` 认可的使用方从只有 module-crew 扩到 module-crew 和 autopilot-hub（来源 ecosystem-lead #23450，用户 2026-11-27 批准措辞）。hub 一组四条：用户打开该仓库自动路时的原话由 hub 记成授权文件；用例取自已批模块的回归测试文档；每条用例一个新的一次性克隆、只跑一轮普通 run，不续跑；`authorization` 字段原样留在结果和 hub 的验证报告里。module-crew 那组四条不变。delegate 仍不读授权文件内容，代码、参数与接口版本都不变。

## 影响面

只改纪律文字：`references/run.md`、`commands/run.md` 与 `delegate-routing` skill 的指向句、插件中英文 README、run-check 中英文规格，以及共享段「职责边界」里「提供给 autopilot-hub」一句。没有改脚本、测试或 `interface.json`。

## 验证与已知限制

`validate.sh --quick`、共享段一致性检查与 `git diff --check` 通过。条件 2、3 是否满足由 hub 负责，delegate 只能核对授权文件可用、整条链同一文件和仓库一致；这是命令指令层面的纪律，不是技术锁。
