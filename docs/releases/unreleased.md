## 参考文件不再要求报告覆盖

`--spec`／`--plan` 带进来、不在本轮审查范围里的参考文件，审查者没提到它们时不再记 `coverage_not_reported`，整轮也不再因此判 `review_incomplete`。0.12.0 起提示词让审查者不对参考文件提发现，审查者也就不报告它们，带 `--spec` 的审查（含 `--profile design`）因此整轮 `failed`。被审文件的覆盖规则不变；审查者主动列出参考文件时照原有规则处理；`scope.files` 仍列出参考文件及其 sha256。合同见[规格](../../spec/review-snapshot-recheck.md) S10。

## 影响面

只改审查结果的覆盖校验，Codex 和 Claude Code 两个后端（含访客路径）都适用。接口版本与报告结构不变。

## 验证与已知限制

单元测试覆盖参考文件未报告、主动列出、被审文件漏报、参考文件同在审查范围里四种情形；桩端到端覆盖 `--paths … --spec …` 在默认档和 `--profile design` 下整轮完成。真实模型的复跑在发版后用安装版进行。
