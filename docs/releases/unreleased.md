# 0.4.0：2026-10-08 审查修复

依据用户确认的修复设计；清单版本为 0.4.0，本轮不自动升级已安装插件，不新增后端或非 Git 支持。

- Codex 在独立进程组中执行；期限默认/上限 540 秒，超时/中断先终止再强制回收组内残余。
- 通过 CLI 登录状态探测，支持 CLI 自身的 CODEX_HOME/钥匙串；拒绝 API key 与未知认证，执行固定 ChatGPT/OpenAI 配置并清除两类 API key 环境变量。
- 已开始的写任务即使失败、超时、空答复或中断也输出 Git 验收；失败不回滚。
- doctor 每次刷新；缓存绑定 CLI/home/插件身份、检查未来时间、原子写入；同事件 hook 改为单入口串行探测后路由。
- 错误日志回显同时限制行数与字节数；总验证纳入全部产品套与新增回归；eval 显式加载源码，首个非空行完整匹配。
- 新增 `/delegate:help`，统一完整命名空间、安装/更新、退出状态、权限和诊断边界；修正旧文档中 auth.json、900秒、无清理、<5ms 和仅 cwd 可写等过期陈述。

限制：本地状态不验证远端/额度；模型确认纪律不是不可绕过的技术锁；脱离进程组的进程不保证回收；日志数量限制不限制单文件大小；后续真实模型验收见 [版本说明](v0.4.0.md)，尚未发布。

本文件记录 0.4.0 的准备内容；正式发行以对应版本标签与发布记录为准。

后续修正 live 测试入口：认证遵循 CLI 状态，不要求 auth.json；日志体量比仅作观察项，不作为固定 40 倍的通过判据。新增回归覆盖无凭据文件但 CLI 已登录、短日志的合法调用。
