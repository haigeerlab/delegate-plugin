# v0.12.0：技术方案审查与第二审查者（接口 1.7）

简体中文 | [English](../en/releases/v0.12.0.md)

这是 v0.11.0 之后的次版本，给生态总账 S110「开发流程改版」用：技术方案由第二审查者对照代码审一轮、修一轮。接口说明从 `1.6` 升到 `1.7`，只增字段；报告 `schema_version` 仍为 `1`。不带新参数时行为不变。

## 变化

### 技术方案审查（`--profile design`）

- `/delegate:review` 新增 `--profile default|design`。`design` 用判据 `design-v1`：只有能指向参考文件（用 `--spec`／`--plan` 带进来、不在审查范围里的文件）某一行、证明照方案做会出错的意见才算阻断。合同见 [design-review-criteria 规格](../../spec/design-review-criteria.md)。
- 拿不出这样一行的阻断，由 delegate 改记为建议并标 `downgraded: "no_code_evidence"`，原文不改；带 `--previous-report` 的第二轮只核对上一轮，新发现一律记为建议（`downgraded: "second_round"`）；design 档里行号核不上的发现不让整轮失败。
- 报告顶层新增 `criteria`（`severity-v1` 或 `design-v1`）；复审时两轮判据必须相同，老报告缺字段按 `severity-v1`。

### 第二审查者的选择（`--backend auto`）

- `/delegate:review` 新增 `--backend auto` 与 `--author-host codex|claude-code`：用无模型检查优先选另一家厂商，否则用同厂商的全新会话；都不可用时出「未审」报告（`conditions_missing`、诊断 `no_reviewer_available`、`backend` 为 `null`、退出 127），不启动模型。合同见 [reviewer-selection 规格](../../spec/reviewer-selection.md)。
- 报告顶层新增 `reviewer: {vendor, backend, same_vendor, selection}`，写明审查者厂商、是否同厂商、怎么选出来的。
- `/delegate:doctor --reviewers [--json]` 列出本机可用的审查者，只有一家时建议再开通一家，不阻止任何操作。
- 审查总是新起会话，写代码的会话不会审自己的东西；文档里原先「Codex 不可用就停下、不改用 Claude 自审」的说法改为此条。

## 影响面

- spec-guard 的技术方案审查（design-review）按 `--profile design` 调用，并用 `--spec` 带上影响面里的已有文件和需求文档。
- 不带 `--profile` 时提示词、判据、校验与 v0.11.0 相同。
- 读报告的一方：「未审」报告的 `backend` 为 `null`（只在 `reviewer.selection == "none"` 时）；`auto` 可能选中 `claude-code`，审查后端不再只有 codex。

## 验证与已知限制

每项行为都先写测试并确认实现前失败。提示词在 Codex、Claude Code 与访客三条路径分别断言；降级、复审判据一致与端到端用桩后端和临时仓库覆盖。

**以下都没有实测：** 真实模型按 `design-v1` 标注的准确度；访客路径（需要一次性虚拟机）。按用法草案 [s110-design-review](../../spec/usage/s110-design-review.md)，发版后用安装版实跑 M1（需调用模型，付费）交用户判定。

本次发版准备实测：免费总验证 466 项 Python，循环注册的 Python 回归套 29 个。

## 更新

- Claude Code：运行 `claude plugin update delegate@delegate-marketplace`，然后打开新会话或执行 `/reload-plugins`。
- Codex：把 `~/.codex/config.toml` 里 `[marketplaces.delegate-marketplace]` 的 `ref` 改成 `"v0.12.0"`，再运行 `codex plugin marketplace upgrade delegate-marketplace` 和 `codex plugin add delegate@delegate-marketplace`，然后重开会话。
