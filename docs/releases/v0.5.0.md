# v0.5.0：双后端只读审查与命令迁移

简体中文 | [English](../en/releases/v0.5.0.md)

delegate 增加可选的 Claude Code Mac 只读审查后端。Claude Code 主会话可委托 Codex，Codex 主会话可委托 Claude Code；用 `--backend codex|claude-code` 明确选择，未指定时仍默认 Codex，不自动切换后端。

## 使用与迁移

- `/delegate:review`：指定路径、模块或固定 diff，执行只读审查；支持 `--context`、范围快捷参数和无模型 `--dry-run`。
- `/delegate:run`：保留 Codex 通用执行；默认只读，只有显式授权的 `--write` 可写入。
- `/delegate:doctor`、`/delegate:help`：按后端检查条件和说明能力。
- **命令迁移**：旧 `/delegate:delegate` 移除。通用任务改用 run，结构化审查改用 review；旧 `codex-exec.sh` 调用保持兼容。Codex 使用相应的 `source-command-*` 技能。

```text
/delegate:review --backend codex --base main --head HEAD
/delegate:review --backend claude-code --paths src --model sonnet --dry-run
```

真正运行 Claude 后端需要原版 Claude Code ≥2.1.295、Node ≥22.12.0、已有 srt 0.0.79 和可用的 Mac 用户 GUI launchd 域。用 `DELEGATE_SRT_BIN` 指定已有 srt 绝对路径；插件不自动安装依赖、登录或修改全局配置。已测试 macOS 15.7.3 arm64，其他平台和版本不作兼容保证。

## 权限与结果

- 后端与模型分别校验，拒绝混用参数。Claude 首版只读，拒绝 write/effort，不开放任意 Bash、MCP、网络和再次派活。
- 使用限定快照、工具权限、OS 文件/网络边界及本次进程清理。沿用正常 CLI 本机认证；自定义认证目录、provider/API 环境覆盖和本地管理配置首版失败关闭。
- 共同报告区分执行状态与审查结论，保留可定位证据和未审范围。空输出、解析失败、拒权、轮次耗尽、超时不视为审查通过。
- 最终答复与过滤后的诊断分开保存，不保留不必要的原始流或凭据；后端未提供用量时不编造零值。
- 修复错误终态拒权/达限诊断、跨后端模型校验和排除文件范围问题。移除每轮路由提醒，避免重复确认或无意的同后端委托。

## 验证与已知限制

免费总验证覆盖 157 项 Python、53 项 shell 和19项 eval。独立实际 Mac OS 权限2项、生命周期6方法及19项证据对账已通过。S2 同一冻结源码的两方向真实四文件审查通过；S6 后续诊断版本真实观察到范围外 Read 拒权，正确报告 failed/inconclusive 和部分范围；S7 验证 Claude 菜单实际脚本与无模型预览。[分层验收记录](../verification/2026-10-14-delegate-layered-acceptance-result.md)保留具体版本和限制。

这些真实记录对应各自的固定源码，发布步骤没有新增模型调用，不冒充最新版本重新完成了双向真实验收。主动模型 Write/递归事件、认证刷新、自然异常 helper、历史认证/设置变化根因、长期稳定性和无差错自动 UI 输入仍未验证。Mac 清理依赖已探测的内核能力；旧 Codex 通用 run 的脱离进程组回收限制保留。不同模型不保证更准确；审查结论不自动授予合并或交付权限。

## 更新

通过宿主插件管理更新 delegate；本地路径 marketplace 的来源必须是期望的源码仓库。更新后在 Claude Code 执行 `/reload-plugins` 或打开新会话；Codex 需重新加载插件入口。安装缓存更新不证明旧会话已经加载新版。

本版还同步双语文档、MIT 清单声明和 Spec Guard 开发约定；Spec Guard 仅辅助规范、计划和验收，不扩展其执行器。产品不依赖 Agent Relay。
