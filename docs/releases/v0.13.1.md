# v0.13.1：审查不再带进被全局忽略的未跟踪文件

简体中文 | [English](../en/releases/v0.13.1.md)

## 审查不再带进被全局忽略的未跟踪文件

`/delegate:review --changes working-tree --include-untracked` 会把只被全局忽略文件（git 默认的 `~/.config/git/ignore` 或 `$XDG_CONFIG_HOME/git/ignore`）忽略的文件当成未跟踪改动发给审查者，实测把本机 `.claude/settings.local.json` 的权限白名单带进了审查输入。原因是 delegate 给 git 子进程准备的环境里没有 `HOME`、`XDG_CONFIG_HOME`，git 找不到默认的全局忽略文件。现在只额外透传这两个变量，全局 git 配置、钩子、fsmonitor、属性文件的隔离不变；无路径的 `--dry-run` 预览同样修正。

## 影响面

- 只影响带 `--include-untracked` 的工作区审查，以及无路径的审查预览：被全局忽略的文件不再进入审查范围。仓库内 `.gitignore` 的行为不变。
- 已知限制：在全局 git 配置里用 `core.excludesFile` 自定义的忽略文件仍不生效（全局配置照旧隔离）；只认 git 默认位置。
- 报告字段、退出码与接口版本（1.8）不变；代码只改了 `review_context.git()` 一处。

## 验证与已知限制

新增回归测试先确认修复前失败：快照层覆盖默认路径与 XDG 路径，并用全局 `diff.noprefix` 确认全局配置仍不生效；CLI 层核对 `--dry-run` 预览清单。修复分支与 v0.13.0 合并后重跑相关套件通过。之前用旧版带 `--include-untracked` 审过的报告，可能已经把被全局忽略的文件发给了审查者，本版不追溯。

本次发版准备实测：免费总验证 589 项 Python，循环注册的 Python 回归套 32 个。
