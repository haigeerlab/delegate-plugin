# v0.12.6：审查命令写明报告取 stdout

简体中文 | [English](../en/releases/v0.12.6.md)

## 审查命令写明报告取 stdout

多个会话并行审查时，有调用方按修改时间取私有目录里最新的报告，会拿到别的仓库的那份。`/delegate:review` 的 stdout 本来就是本次报告的完整 JSON，stderr 的 `delegate: artifacts=<路径>` 指向本次私有副本；现在命令说明写明：报告取 stdout，私有副本只认本次 `artifacts=` 路径，不按时间取最新。

另外删除了无人调用的开发脚本 `scripts/check-frontmatter.py`（CI 早已改用公共校验器），不进安装包。

## 影响面

只改 review 命令说明一句话。代码、报告字段、退出码与接口版本（1.7）不变；run 和 Codex 后端不受影响。

## 验证与已知限制

`validate.sh` 全量与命令渲染字节预算（不超过 4000）通过。已按时间取最新报告的调用方须自行改为读 stdout，本版不替它们改。

本次发版准备实测：免费总验证 551 项 Python，循环注册的 Python 回归套 31 个。

## 更新

- Claude Code：运行 `claude plugin update delegate@delegate-marketplace`，然后打开新会话或执行 `/reload-plugins`。
- Codex：把 `~/.codex/config.toml` 里 `[marketplaces.delegate-marketplace]` 的 `ref` 改成 `"v0.12.6"`，再运行 `codex plugin marketplace upgrade delegate-marketplace` 和 `codex plugin add delegate@delegate-marketplace`，然后重开会话。
