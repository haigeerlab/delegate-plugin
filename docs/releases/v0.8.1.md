# v0.8.1：文档跟上接口 1.3

简体中文 | [English](../en/releases/v0.8.1.md)

这是 v0.8.0 之后的补丁版，**只改文档，行为不变**。接口说明仍为 `1.3`，脚本、命令参数、期限、结果行、结果文件和退出码都与 v0.8.0 相同；不需要迁移。

v0.8.0 只给 `/delegate:run` 的 Codex 后端加了执行能力（`--continue`、`--timeout`、结果文件与 `--strict`、`--check`、`--authorized-by`、`--rules-file`），Claude Code 后端仍只做只读审查。v0.8.0 发版时插件 README、`commands/run.md`、`references/run.md` 和新规格已经写了这些能力，但还有几处文档停在旧说法上，本版补齐。

## 修正

- **根 README（中英文）**：开头介绍改为概括当前能力，并点明执行能力只在 Codex 后端；「不提供后台任务、断点续跑」改为准确的边界——有续跑（`--resume`）和续接（`--continue`），但不托管后台进程，长任务由调用方用宿主后台模式调用；参数表补上 `--resumable`、`--resume`、`--continue`、`--timeout`、`--strict`、`--check`、`--authorized-by`、`--rules-file`，并写明它们只适用于 Codex 后端；「期限默认和上限 540 秒」改为默认 540 秒、`--timeout` 可放大到 541～7200 秒，`DELEGATE_TIMEOUT_SECONDS` 只能缩短默认值。
- **插件内 `/delegate:help`**：补上 1.3 参数的简要说明，并指向 `references/run.md`。为了不超过 Codex 转换命令 skill 的 4000 字节上限，同时压缩了三处重复说法（版本复述、验收记录位置、菜单核对说明），没有删去任何参数或纪律。
- **插件内 `delegate-routing` skill**：补写 `--timeout` 超过 540 秒必须用宿主后台模式调用、等完成通知、不轮询；补写 `--continue` 只接 `--resumable` 链上状态为 `done` 的一轮。`--write` 的授权规则不变。
- **设计文档（中英文）**：改掉「期限默认/上限 540 秒」「无断点恢复」。
- **文档索引（中英文）**：补上 run-result、run-continue、run-longrun、run-check、run-rules 五份规格和模块清单的链接。
- **英文能力图**：补上这五个模块和新的构建顺序，与中文能力图一致。

## 验证与已知限制

没有改代码和测试。免费总验证仍为 328 项 Python、53 项 shell 和 19 项 eval，25 个循环注册的 Python 回归套；`claude plugin validate` 对 marketplace 和插件都通过。

v0.8.0 列为未验证的「`--timeout` 超过 540 秒的真实运行」已在 2026-10-27 补测（[记录](../verification/2026-10-27-delegate-timeout-longrun-live.md)，2 次只读付费调用）：`--timeout 900` 运行 615 秒正常完成；`--timeout 600` 在 555 秒中止、退出 124，中止后无残留进程。本版没有新的付费调用。v0.8.0 列出的其余未验证项不变。

## 更新

运行 `claude plugin update delegate@delegate-marketplace`，然后打开新会话或执行 `/reload-plugins`。从 v0.8.0 升级不需要迁移。
