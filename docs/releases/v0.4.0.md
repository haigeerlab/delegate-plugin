# delegate v0.4.0

将已定方案的执行与查证交给 Codex CLI，主会话接收最终答复，过程日志留在本机。本版集中修复执行生命周期、认证、Git 验收和接入诊断，并补全使用帮助。

## 新增

- `/delegate:help` 提供命令、参数、使用场景和故障帮助。
- wrapper `--help` / `-h` 可在没有 Codex 时显示参数用法。

## 修复与改进

- 超时、中断与正常退出时清理执行进程组；超时先 TERM，等待最多 2 秒后强制终止残余进程。
- 通过 CLI 登录状态判断 ChatGPT 认证，支持 CLI 自身的 Codex home 与钥匙串存储；不以 auth.json 文件存在为判据。
- 执行时清除两类 API key 环境变量，并指定 ChatGPT 登录和 OpenAI provider；未知认证状态保持拒绝。
- 已开始的写模式任务即使失败、超时或答复为空，仍返回 Git 概览；失败不会自动回滚已发生的修改。
- doctor 每次刷新本地基础条件；缓存绑定 CLI/home/插件身份，原子写入；提示 hook 串行预热后路由。
- 失败日志回显最多 40 行 / 16KiB；尽力保留最近 50 组过程日志与答复。
- 总验证纳入全部产品套，行为评估显式加载当前源码，判决只接受首个非空行完整格式。

## 从 0.3.x 升级时的变化

| 项目 | 0.4.0 约定 |
|---|---|
| 认证 | 仅接受 ChatGPT 登录；API key 或未知登录状态被拒绝 |
| 执行期限 | 默认和上限 540 秒；环境变量可缩短，上限以上会截断，非法或非正值回落默认 |
| 工作目录 | 所有调用都必须在 Git 工作区，不提供非 Git 绕过 |
| 命令名 | 使用 `/delegate:delegate`、`/delegate:doctor`、`/delegate:help` 完整命名空间 |
| 写模式失败 | 查看 stderr 中的 Git 证据，人工验收修改；不能认为失败就没有改文件 |
| doctor | 会刷新临时缓存，退出 0 表示诊断完成，以文本的问题数量为准 |
| 日志压缩率 | 体量比只是观察值，不承诺固定 40 倍收益 |

本版按 0.4.0 编号，因为认证和超时范围的收紧对使用者有可见影响，不作为普通补丁隐藏。

## 安装与升级

在取得本版本源码后，进入插件仓库目录：

```bash
claude plugin marketplace add "$PWD"
claude plugin install delegate@delegate-marketplace
```

已有安装由用户主动更新：

```bash
claude plugin update delegate@delegate-marketplace
```

运行 `/delegate:doctor`，核实 `codex login status` 为 ChatGPT 登录，再在业务 Git 项目中尝试一个小的只读任务。源码目录变化不会自动更新安装缓存。

## 验证范围

- 免费验证：52 条原有断言与 17 个 Python 回归测试，清单/语法/判决器检查通过。
- 真实模型样本：只读读取、授权后写入及 Git 证据、两项 Claude 行为评估、帮助命令加载通过。
- headless 评估不保证交互时每次会主动提议；本地登录状态不保证远端、额度或模型权限。

## 回退与保障边界

如遇影响使用的回归，可先停止委托，保留现有 Git 修改和日志，另取已知版本的源码通过 `--plugin-dir` 排障。回退不会自动撤销模型已经写入的文件；旧版本也会恢复其旧认证与生命周期行为。安装缓存的调整由用户主动操作。

确认、不提交/推送等要求是模型行为指令；wrapper 没有不可绕过的授权锁。真实沙箱权限由 Codex 和宿主配置决定；脱离进程组的后代不保证被回收。Git 概览不能证明代码正确性，日志数量限制不限制单文件大小。
