# delegate v0.3.1

简体中文 | [English](../en/releases/v0.3.1.md)

历史发行记录：以下内容保留 v0.3.1 当时的描述。安装、完整命令名、认证与保障边界以当前 [README](../../README.md) 和 [v0.4.0 升级说明](v0.4.0.md) 为准，旧版措辞不构成当前实现保证。

`delegate` 是一条 Claude Code 到 Codex CLI 的受控委托通道：把已经决策完毕的执行与查证工作交给 Codex，只把结论带回主会话。

## 为什么存在

主会话不应持续承载大段搜索输出、文件阅读和测试日志。`delegate` 将这些高上下文消耗的过程隔离到执行端，让 Claude 保留方案判断、范围控制和最终验收。

## 适合委托的工作

当方案、范围和验收标准已经明确，只剩执行或查证时，可以委托：代码审查、跨文件梳理、复现与定位问题、单个明确 task 的实现，以及批量机械改动。仍需需求澄清或架构取舍时，应留在 Claude。

## 安全边界

- 绝不自动委托：先说明委托内容，等待用户明确确认。
- 默认只读；只有用户在当前轮明确要求 `--write` 才允许写入。
- 写模式返回 Git 验收块，不能只相信执行器自述。
- Codex 不可用时静默降级，不注入误导性提示。
- 过程日志留在临时目录，主会话只接收最终答复。

## 安装与首次使用

以下代码保留历史示例，包括旧版简写命令形式：

```bash
claude plugin marketplace add <本仓库路径或 URL>
claude plugin install delegate@delegate-marketplace
/delegate:doctor
```

默认只读：

```bash
/delegate <任务>
```

只有明确需要修改工作区时才使用 `--write`，并在返回后查看 Git 验收块。

## 已知限制

- 当前后端只有 Codex CLI；不提供多后端路由或持久后台任务控制面。
- `auth.json` 存在不代表登录 token 仍然有效。
- “该提议时是否一定会提议”目前没有完整自动化验证；硬性保证是绝不自动委托。

完整设计见 [DESIGN.md](../../DESIGN.md)，安装、参数与验证命令见 [README.md](../../README.md)。
