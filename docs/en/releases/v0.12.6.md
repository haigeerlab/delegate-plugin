# v0.12.6: Review command states the report comes from stdout

[简体中文](../../releases/v0.12.6.md) | English

## Review command states the report comes from stdout

When several sessions review in parallel, a caller that picked the newest report in the private directory by modification time could get another repository's report. The standard output of `/delegate:review` already is this run's full JSON report, and `delegate: artifacts=<path>` on stderr points to this run's private copy. The command description now says so: take the report from stdout, use only this run's `artifacts=` path for the private copy, and never pick the newest by time.

The unused development script `scripts/check-frontmatter.py` was also removed (CI moved to the shared validator long ago); it is not part of the installed plugin.

## Impact

Only one sentence of the review command description changes. Code, report fields, exit codes and interface version (1.7) are unchanged; run and the Codex backend are unaffected.

## Validation and known limitations

Full `validate.sh` and the rendered command byte budget (at most 4000) pass. Callers that pick the newest report by time must switch to stdout themselves; this release does not change them.

Release preparation measured: free validation 551 Python tests, 31 loop-registered Python regression suites.

## Update

- Claude Code: run `claude plugin update delegate@delegate-marketplace`, then open a new session or run `/reload-plugins`.
- Codex: change `ref` in `[marketplaces.delegate-marketplace]` of `~/.codex/config.toml` to `"v0.12.6"`, run `codex plugin marketplace upgrade delegate-marketplace` and `codex plugin add delegate@delegate-marketplace`, then reopen the session.
