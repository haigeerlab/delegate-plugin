# v0.5.3: Published interface description and review report contract

[简体中文](../../releases/v0.5.3.md) | English

A minor release after v0.5.2. Commands, parameters, permission boundaries and report contents are unchanged. Upgrading from v0.5.2 needs no migration.

## Added

- **`interface.json`**: a new interface description at the plugin root (interface version `1.0`). It declares that `/delegate:review` supports two read-only backends, codex and claude-code, with report `schemaVersion: 1`, and that `/delegate:run` supports only codex, with writes requiring explicit authorization. Other plugins can check a version range such as `>=1.0,<2.0` instead of reading delegate internals. `backends` lists supported backends only, not ones installed, signed in or funded on this machine; whether they run is still decided by `/delegate:doctor`.
- **External review report contract**: the plugin README has a new "External interface" section stating that the standard output of `/delegate:review` is the report JSON, listing the v1 stable fields (execution status, review outcome, backend, review target fingerprint, reviewed and unreviewed files, findings, limitations) and the interpretation rules: a review has a conclusion only when `execution_status=completed` and the outcome is `findings` or `no_findings_in_scope`; a report is an opinion, not user approval.
- **Consistency test**: the new `test-interface.py` compares the interface description and report contract against source facts, so changing fields or backends fails the test.

## Validation and known limits

Free aggregate validation covers 173 Python cases (7 more than v0.5.2), 53 shell and 19 eval; `claude plugin validate` passes for both the marketplace and the plugin. This release adds only a static file, a test and documentation, with no new model calls.

Consumer integration is implemented by each plugin: the current spec-guard release suggests `/delegate:review` based only on the plugin being installed and enabled, and version-range checks will follow after this release. The other unverified items listed for v0.5.0 are unchanged.

## Updating

Run `claude plugin update delegate@delegate-marketplace`, then open a new session or run `/reload-plugins`.
