# delegate v0.3.1

`delegate` is a controlled delegation channel from Claude Code to Codex CLI: send execution and investigation work whose decisions are already settled to Codex, returning only the conclusion to the main session.

## Why it exists

The main session should not continually carry large search outputs, file-reading traces, and test logs. delegate isolates those processes in the executor, allowing Claude to retain design judgment, scope control, and final verification.

## Suitable work

When the approach, scope, and acceptance criteria are settled and only execution or investigation remains, suitable work includes code review, exploration across files, reproduction and diagnosis, implementing a specific task, and mechanical batch edits. Requirements and architectural trade-offs remain with Claude.

## Safety boundaries

- Never delegate automatically: describe the task first and wait for explicit confirmation.
- Default to read-only; permit writes only when the user explicitly requests `--write` in the current turn.
- Write mode returns a Git verification block; do not trust only the executor's own report.
- Degrade silently when Codex is unavailable, without injecting misleading hints.
- Keep process logs in temporary storage; the main session receives only the final answer.

## Installation and first use

The following commands preserve the historical examples, including the old short command form:

```bash
claude plugin marketplace add <repository-path-or-URL>
claude plugin install delegate@delegate-marketplace
/delegate:doctor
```

Default read-only:

```bash
/delegate <task>
```

Use `--write` only when working-tree changes are explicitly needed, and inspect the Git verification block afterward.

## Known limitations

- Codex CLI is the only backend; no multiple-backend routing or persistent background-task control plane.
- The existence of `auth.json` does not establish that the login token remains valid.
- Whether delegation is always proposed when appropriate lacks complete automated verification; this historical description identifies avoiding automatic delegation as its strict guarantee.
