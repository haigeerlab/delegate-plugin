# v0.8.2: The run command description catches up with interface 1.3

[简体中文](../../releases/v0.8.2.md) | English

A patch release after v0.8.1 that **changes only the `/delegate:run` command description; behavior is unchanged**. The interface description stays `1.3`; scripts, command options, deadlines, the result line, the result file and exit statuses are the same as in v0.8.1, and no migration is needed.

`commands/run.md` is the prompt the host loads when it calls `/delegate:run` (module-crew's module sessions call it this way). v0.8.1 brought the other documents up to date, but this prompt still had two statements written before 1.3; this release corrects them.

## Fixes

- **Write authorization**: it used to say `--write` may be added only when the user explicitly asks for writes in that turn. It now says `--write` requires the user's explicit request in that turn, with one exception: all four write-authorization conditions in `references/run.md` are met and `--authorized-by` is given; if any condition is not met, the in-turn request is required again, and permissions are never escalated on the model's own initiative. This exception was approved in v0.8.0 in [run-check](../SPEC-run-check.md) and already written into `references/run.md` and the `delegate-routing` skill; this release only states it in the command description and loosens no condition.
- **Deadline**: it used to say "default and maximum 540 seconds". It now says the default is 540 seconds, `--timeout` lifts it to 541–7200 seconds, and above 540 seconds the call must use the host's background mode ([run-longrun](../SPEC-run-longrun.md) S9).
- **Log location**: "old process logs are in…" now reads "process logs and result files are in…", matching the 1.3 result file.
- **To stay within Codex's 4,000-byte limit** (Codex skips a converted command skill above it), three repeated statements were removed: "use review for shared structured reviews too" (the same line already says Claude provides read-only review only through `/delegate:review`), "does not use the locally configured approval mode" (`approval_policy="never"` is already stated), and the v0.5.0 migration note (the full migration notes remain in `/delegate:help`). The converted size is now 3,971 bytes.

The `delegate-routing` skill was checked and has no outdated statements; it is unchanged in this release.

## Validation and known limitations

No code or tests changed. Free validation still covers 328 Python, 53 shell and 19 eval checks, with 25 loop-registered Python regression suites; the command size test passes; `claude plugin validate` passes for both the marketplace and the plugin. This release makes no paid calls.

The root README and the plugin README say "use background mode when `--timeout` exceeds the host's foreground limit", while the command description and the skill follow S9: "use background mode above 540 seconds". Both wordings come from the run-longrun specification, and the latter is stricter; this release does not reconcile them. The other unverified items listed in v0.8.0 are unchanged.

## Update

Run `claude plugin update delegate@delegate-marketplace`, then open a new session or run `/reload-plugins`. Upgrading from v0.8.1 needs no migration; sessions already using `/delegate:run` must reload to read the new command description.
