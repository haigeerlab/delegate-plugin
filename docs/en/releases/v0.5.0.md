# v0.5.0: dual-backend read-only review and command migration

[简体中文](../../releases/v0.5.0.md) | English

delegate adds optional Mac Claude Code read-only review. A Claude Code main session can delegate to Codex, and a Codex main session can delegate to Claude Code. Select `--backend codex|claude-code`; Codex remains the default, without automatic fallback.

## Usage and migration

- `/delegate:review`: bounded paths, modules or fixed diffs, advanced `--context`, scope shortcuts and model-free `--dry-run`.
- `/delegate:run`: existing general Codex execution, read-only by default; writes require explicit authorization and `--write`.
- `/delegate:doctor` and `/delegate:help`: backend-specific prerequisites and capabilities.
- **Command migration:** `/delegate:delegate` is removed. Use run for general tasks and review for structured reviews. Legacy `codex-exec.sh` calls remain compatible. Codex exposes matching `source-command-*` skills.

```text
/delegate:review --backend codex --base main --head HEAD
/delegate:review --backend claude-code --paths src --model sonnet --dry-run
```

Actual Claude execution needs original Claude Code ≥2.1.295, Node ≥22.12.0, existing srt 0.0.79 and an available Mac user GUI launchd domain. Supply the existing absolute srt path through `DELEGATE_SRT_BIN`. The plugin does not install dependencies, log in or change global configuration. macOS 15.7.3 arm64 was tested; other platforms/versions are not guaranteed.

## Permissions and results

- Validate backend/model separately and reject mixed parameters. Claude v1 is read-only, rejects write/effort, and exposes no arbitrary Bash, MCP, network or further delegation.
- Bound snapshots, tool permissions, OS file/network isolation and invocation-specific process cleanup. Reuse normal local CLI authentication. Custom auth directories, provider/API environment overrides and local managed configuration fail closed in v1.
- Shared results distinguish execution status from review findings, preserve evidence and uncovered scope, and never treat empty/invalid output, denials, turn exhaustion or timeouts as a pass.
- Separate final answers and filtered diagnostics, without unnecessary raw streams or credentials. Missing usage is not reported as zero.
- Fix error-terminal denial/limit diagnostics, cross-backend model validation and excluded-file scoping. Remove per-prompt routing reminders and unintended same-backend delegation/repeated confirmations.

## Updating

Update delegate through the host plugin manager; local marketplaces must reference the intended repository. Run `/reload-plugins` or open a new Claude Code session, and reload Codex plugin entries. Updated caches do not establish that existing sessions loaded the release.

This release also synchronizes bilingual documentation, MIT manifest metadata and Spec Guard development conventions. Spec Guard assists specifications/plans/acceptance without gaining an executor. Agent Relay is not a product dependency.
