# v0.8.1: Documentation catches up with interface 1.3

[简体中文](../../releases/v0.8.1.md) | English

A patch release after v0.8.0 that **changes documentation only; behavior is unchanged**. The interface description stays `1.3`; scripts, command options, deadlines, the result line, the result file and exit statuses are the same as in v0.8.0, and no migration is needed.

v0.8.0 added execution capabilities only to the Codex backend of `/delegate:run` (`--continue`, `--timeout`, the result file and `--strict`, `--check`, `--authorized-by`, `--rules-file`); the Claude Code backend still performs read-only review only. When v0.8.0 shipped, the plugin README, `commands/run.md`, `references/run.md` and the new specifications already described these capabilities, but several other documents still carried older statements. This release brings them up to date.

## Fixes

- **Root README (Chinese and English)**: the introduction now summarizes current capabilities and states that execution capabilities exist only on the Codex backend; "no background jobs or resumption" now states the actual boundary — resumption (`--resume`) and continuation (`--continue`) exist, but delegate hosts no background process and the caller runs long tasks in the host's background mode; the option table adds `--resumable`, `--resume`, `--continue`, `--timeout`, `--strict`, `--check`, `--authorized-by` and `--rules-file`, noting that they apply only to the Codex backend; "the deadline defaults to and is capped at 540 seconds" now reads: default 540 seconds, `--timeout` lifts it to 541–7200 seconds, and `DELEGATE_TIMEOUT_SECONDS` can only shorten the default.
- **Plugin `/delegate:help`**: adds a short description of the 1.3 options and points to `references/run.md`. To stay within the 4,000-byte limit Codex applies to converted command skills, three repeated statements (a version restatement, the location of acceptance records, the menu check note) were shortened; no option or rule was removed.
- **Plugin `delegate-routing` skill**: adds that `--timeout` above 540 seconds must be called in the host's background mode, waiting for the completion notice without polling, and that `--continue` accepts only a round with status `done` on a `--resumable` chain. The `--write` authorization rule is unchanged.
- **Design document (Chinese and English)**: removes "the deadline defaults to and is capped at 540 seconds" and "no resumption".
- **Documentation index (Chinese and English)**: adds links to the run-result, run-continue, run-longrun, run-check and run-rules specifications and module checklists.
- **English capability map**: adds these five modules and the new build order, matching the Chinese capability map.

## Validation and known limitations

No code or tests changed. Free validation still covers 328 Python, 53 shell and 19 eval checks, with 25 loop-registered Python regression suites; `claude plugin validate` passes for both the marketplace and the plugin.

The "real run with `--timeout` above 540 seconds" that v0.8.0 listed as unverified was tested on 2026-10-27 ([record](../../verification/2026-10-27-delegate-timeout-longrun-live.md), in Chinese; 2 read-only paid calls): `--timeout 900` completed normally after 615 seconds; `--timeout 600` was aborted at 555 seconds with exit 124 and no processes left behind. This release makes no new paid calls. The other unverified items listed in v0.8.0 are unchanged.

## Update

Run `claude plugin update delegate@delegate-marketplace`, then open a new session or run `/reload-plugins`. Upgrading from v0.8.0 needs no migration.
