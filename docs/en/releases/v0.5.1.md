# v0.5.1: Claude review backend wrongly refused in Claude Desktop

[简体中文](../../releases/v0.5.1.md) | English

This is a fix release after v0.5.0. Commands, options, and permission boundaries are unchanged, and upgrading from v0.5.0 needs no migration.

## Fix

- **Claude backend refused in Claude Desktop**: running `/delegate:review --backend claude-code` or `/delegate:doctor --backend claude-code` in a Claude Desktop Code session always failed with `native_authentication_environment_unverified`. Desktop injects `ANTHROPIC_BASE_URL=https://api.anthropic.com` into every session, and the plugin treated it as a custom provider. It is now accepted only when it normalizes to the official default endpoint: https, host `api.anthropic.com` (case-insensitive), empty port or 443, and an empty or `/` path. Any other value, and all other authentication or provider variables, remain refused. The child environment never inherited the variable, so the endpoint actually used is unchanged.

## Verification and known limits

Free validation covers 162 Python tests (five more regression cases than v0.5.0), 53 shell assertions, and 19 evals; `claude plugin validate` passes for both the marketplace and the plugin. The official-endpoint check was also differentially tested with 15 boundary inputs: http, spoofed subdomains, user info, paths or queries, other ports, a trailing dot, and URL-encoding tricks are all refused.

This release made no model calls. A complete Claude backend doctor run inside Claude Desktop and real model reviews remain unverified: the verification machine has no srt installed, so doctor stops at `sandbox_runtime_missing` after the authentication check. The other unverified items listed for v0.5.0 are unchanged.

## Updating

Run `claude plugin update delegate@delegate-marketplace`, then open a new session or run `/reload-plugins`. The host replaces the old installation cache only when the version changes. The Claude backend still needs an existing local srt 0.0.79, on `PATH` or set with `DELEGATE_SRT_BIN` as an absolute path.
