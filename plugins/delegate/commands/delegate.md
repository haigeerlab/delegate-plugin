仅在用户已明确授权本次委托后，把已决策完毕的任务交给 Codex。用户直接输入本命令表示授权其明确任务；模型主动提议后必须等待肯定答复。只原样委托用户在本轮明确交代的任务；不要补充、扩展或推断范围。

调用方式：

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/codex-exec.sh" [选项] "<任务>"
```

`<任务>` 必须作为一个完整参数传入，必须加引号。调用 Bash 时把 timeout 设为 `600000`；默认的 120 秒对 Codex 经常不够，超时会白烧一次调用。

当前目录必须是业务 Git 工作区，否则直接拒绝；默认是只读。只有用户在**该轮**明确要求写文件时才可以加 `--write`；不得自行升级为写模式。

`--write` 返回后，无论成功、失败、超时或空答复，都必须查看 git 验收块和真实 diff：基线 HEAD、原有变更数量、status、未暂存/已暂存统计。失败不会自动回滚，不能只相信 Codex 的自述。

wrapper 只返回最终答复；过程日志保存在 `${TMPDIR}/delegate/`。需要证据时，按输出给出的路径用 `sed -n` 取所需几行；不要 `cat` 整个日志，否则会把节省下来的上下文重新灌回来。

本地参数帮助可调用脚本 `--help`，用户帮助见 `/delegate:help`，接入检查见 `/delegate:doctor`。Codex 执行期限默认/上限 540 秒；超时/中断回收执行进程组。基础检查只接受 ChatGPT 登录，不验证远端/额度。确认与不提交/推送等是行为指令；实际可写范围由 Codex 沙箱及宿主配置决定。
